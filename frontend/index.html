Why Hybrid Cryptography?

Symmetric encryption algorithms like AES-256 are computationally fast and ideal for encrypting large files, but require secure key transmission. Asymmetric algorithms like RSA-2048 provide secure key exchange using public/private key pairs, but are too slow for large files. Hybrid Cryptography combines the speed of AES-256 with the key-protection security of RSA-2048.

How Isolation Forest ML Detection Works

Isolation Forest is an unsupervised machine learning algorithm that isolates anomalies by randomly partitioning feature space using decision trees. Because anomalous activity (e.g. repeated decryption failures or rapid automated requests) occurs infrequently and differs significantly from normal baseline activity, it requires fewer splits to isolate, resulting in a negative anomaly score.
